# Материалы разработки шаблона

Каталог относится к самому шаблону и в проекты не переносится (`install-into-repo.sh` его не копирует). При создании проекта клонированием шаблона каталог можно удалить.

| Каталог | Содержание |
|---|---|
| `poc/` | проверка herdr-core в WSL перед v0.2 |
| `v0.2/` | независимые ревью v0.2 (Codex, Claude), отчёт исправлений ядра, smoke-тест воркера OpenCode |
